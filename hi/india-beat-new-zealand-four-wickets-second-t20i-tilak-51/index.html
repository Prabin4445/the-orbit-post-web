    Dusre T20I mein Bhaarat ne New Zealand ko chaar wicket se haraaya, Tilak Varma 51 not out

    Tilak Varma aur Nitish Kumar Reddy ne saatve wicket ke liye 30 gendon mein 69 run ki record saajhedaari ki, aur Bhaarat ne Hagley Oval mein ek gend baaki rahte 181 run ka peechha karke series mein 2-0 ki badhat le li.

    मुख्य बिंदु

    • Bhaarat ne Christchurch ke Hagley Oval mein shanivaar, 24 October 2026 ko khele gaye dusre T20 antarrashtriya match mein New Zealand ko chaar wicket se haraaya.

    Bhaarat ne Christchurch ke Hagley Oval mein shanivaar, 24 October 2026 ko khele gaye dusre T20 antarrashtriya match mein New Zealand ko chaar wicket se haraaya. Bhaarat 19.5 over mein chhah wicket par 181 run banakar lakshya tak pahuncha, ek gend baaki rahte, aur paanch matchon ki series mein 2-0 ki badhat le li.

    Tilak Varma 51 run par not out rahe aur unhe Player of the Match chuna gaya. Nitish Kumar Reddy ke saath unki saajhedaari ne Bhaarat ko 112 run par chhah wicket ki sthiti se nikala aur us lakshya ko pura kiya jise New Zealand ke kaptan Mitchell Santner ne chaar wicket lekar mushkil bana diya tha.

    विज्ञापन

    Phillips aur Jacobs ne lakshya khada kiya

    Pahle ballebaazi ke liye bulaayi gayi New Zealand ne 20 over mein paanch wicket par 180 run banaye. Glenn Phillips ne 43 gendon par 70 run banakar sabse zyada score kiya, aur Bevon Jacobs ne 46 gendon par 58 run banaye. Is jodi ne mezbaan team ko aisa kul score diya jo usi maidaan par pratispardhi lag raha tha jahan Bhaarat ne do din pahle 226 run ka peechha kiya tha.

    Arshdeep Singh Bhaarat ke sabse safal gendbaaz rahe, unhone 33 run dekar do wicket liye. Bhuvneshwar Kumar, Prince Yadav aur Nitish Kumar Reddy ne ek ek wicket liya, aur Bhaarat ne New Zealand ko poori paari mein paanch wicket par rok diya.

    Santner ne peechha roka

    Bhaarat ne tez shuruaat ki. Sanju Samson aur Abhishek Sharma ne 4.4 over mein 40 run jode, iske baad Santner ne lakshya ke peechhe bhaagne ka rukh badal diya. Teesre number par ballebaazi karne aaye Vaibhav Sooryavanshi ne 8 gendon par 4 run banaye, aur beech ke overon mein wicket lagatar girte rahe.

    Santner ne 21 run dekar chaar wicket liye. 15ve over tak Bhaarat 112 run par chhah wicket par phisal gaya tha aur use ab bhi 69 run chahiye the. Naman Dhir ne 17 gendon par 31 run banaye the aur Tilak ke saath 42 run jode the, 112 run par chhah wicket ki sthiti par out hone se pahle, jisse lakshya saatve wicket ki jodi ke haathon mein reh gaya.

    Record saajhedaari ne kaam tamaam kiya

    Tilak aur Reddy ne iske baad match New Zealand se chheen liya. Unki atoot saatve wicket ki saajhedaari 30 gendon mein 69 run ki rahi, jo T20 antarrashtriya mein saatve wicket ke liye Bhaarat ka record hai. Isne Dinesh Karthik aur Krunal Pandya ke 63 run ke pichhle record ko peechhe chhod diya.

    Tilak 26 gendon par chhah chaukon aur ek chhakke ke saath 51 run par not out rahe. Reddy 13 gendon par 26 run par not out rahe aur unhone vijayi run banaye, ek gend baaki rahte match khatm kiya. Yeh nateeja 22 October ko usi maidaan par khele gaye pahle T20 antarrashtriya mein Bhaarat ki chaar wicket ki jeet ke baad aaya hai, jahan unhone 226 run ka peechha kiya tha, aur isse New Zealand ko series jeetne ke liye baaki match jeetne hi honge.

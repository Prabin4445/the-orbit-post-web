    Dosro T20I ma Bhaaratle New Zealand lai chaar wicket le haraayo, Tilak Varma 51 not out

    Tilak Varma ra Nitish Kumar Reddy le saataun wicket ka laagi 30 ball ma 69 run ko record sajhedaari gare, ra Bhaaratle Hagley Oval ma ek ball baanki rahanda 181 run pachhyaayera shringkhala ma 2-0 ko agrata liyo.

    मुख्य बुँदाहरू

    • Bhaaratle Christchurch ko Hagley Oval ma shanibaar, 24 October 2026 ma bhaeko dosro T20 antarrashtriya khel ma New Zealand lai chaar wicket le haraayo.
    • Tilak Varma 51 run ma not out rahe ra khel ko sarbottam khelaadi ghoshit bhae.
    • Pahile batting garna bhaniye ko New Zealand le 20 over ma paanch wicket gumaayera 180 run banaayo.

    Bhaaratle Christchurch ko Hagley Oval ma shanibaar, 24 October 2026 ma bhaeko dosro T20 antarrashtriya khel ma New Zealand lai chaar wicket le haraayo. Bhaarat 19.5 over ma 181 run chha wicket gumaayera lakshya samma pugyo, ek ball baanki rahanda, ra paanch khel ko shringkhala ma 2-0 ko agrata liyo.

    Tilak Varma 51 run ma not out rahe ra khel ko sarbottam khelaadi ghoshit bhae. Nitish Kumar Reddy sanga ko unko sajhedaari le Bhaarat lai 112 run ma chha wicket ko awastha bata bachaayo ra New Zealand ka kaptan Mitchell Santner le chaar wicket liyera kathin banaeko lakshya pachhyaune kaam pura garyo.

    विज्ञापन

    Phillips ra Jacobs le lakshya khada gare

    Pahile batting garna bhaniye ko New Zealand le 20 over ma paanch wicket gumaayera 180 run banaayo. Glenn Phillips le 43 ball ma 70 run banaayera sarbaadhik score gare, ra Bevon Jacobs le 46 ball ma 58 run banaae. Jodi le gharelu toli lai yasto kul diyo june dui din aghi Bhaaratle 226 run pachhyaeko maidaan ma pratispardhi dekhintheo.

    Arshdeep Singh Bhaarat ka sabai bhanda safal bowler bhae, 33 run diera dui wicket lie. Bhuvneshwar Kumar, Prince Yadav ra Nitish Kumar Reddy le ek ek wicket lie, ra Bhaaratle New Zealand lai pura innings ma paanch wicket mai seemit rakhyo.

    Santner le pachhyaune kaam roke

    Bhaaratle chhito suru garyo. Sanju Samson ra Abhishek Sharma le 4.4 over ma 40 run jode, tes pachi Santner le lakshya pachhyaune khel ko disha badale. Tesro number ma batting gareka Vaibhav Sooryavanshi le 8 ball ma 4 run banaae, ra bicha ko over haru ma wicket haru lagatar jhare.

    Santner le 21 run diera chaar wicket lie. 15 aun over samma Bhaarat 112 run ma chha wicket ma jhareko thiyo ra ajhai 69 run chahintheo. Naman Dhir le 17 ball ma 31 run banaeka thie ra Tilak sanga 42 run jodeka thie, 112 run ma chha wicket ko awastha ma out hunu aghi, jasle lakshya pachhyaune jimmewaari saataun wicket ko jodi ma chhodyo.

    Record sajhedaari le kaam sakyo

    Tilak ra Reddy le tes pachi khel New Zealand bata khose. Uniharuko na tuteko saataun wicket sajhedaari 30 ball ma 69 run ko bhayo, june T20 antarrashtriya ma saataun wicket ka laagi Bhaarat ko record ho. Yasle Dinesh Karthik ra Krunal Pandya ko 63 run ko aghillo record lai paar garyo.

    Tilak 26 ball ma chha chauka ra ek chhakka sahit 51 run ma not out rahe. Reddy 13 ball ma 26 run ma not out rahe ra vijayi run banaae, ek ball baanki rahanda khel sakaae. Yo natija 22 October ma eutai maidaan ma bhaeko pahilo T20 antarrashtriya ma Bhaarat ko chaar wicket ko jeet pachhi aayeko ho, jaha uniharule 226 run pachhyaeka thie, ra yasle New Zealand lai shringkhala jitna baanki khel haru jitnai parne awastha ma rakheko chha.
